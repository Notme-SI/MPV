# mpv+ v1.0.1

### Windows

- 🎨 **Интерфейс:** обновлено оформление, добавлены русский и английский языки.
- ▶️ **TorrServer:** плейлисты, выбор серий и доступ к добавленным фильмам и сериалам.
- ⏭️ **Пропуски:** заставки, рекапы и титры, включая аниме при наличии таймкодов.
- 🖼️ **Изображение:** автоматическая обрезка чёрных полос с возможностью отключения.
- 🔊 **Дорожки:** предпочтительные языки озвучки и субтитров, форсированные субтитры и запоминание выбора между сериями.
- 🪟 **Окно:** сохранение размера и режим «Поверх всех окон».
- 🌐 **Сеть:** восстановление после обрыва, настройка буфера и диагностика потока.
