mpv+ 1.0.2 — Windows 10/11 x64

Запуск: mpv+.exe. Для внешнего плеера Lampa Desktop выберите mpv.exe
из этой же папки: это совместимый запускатель mpv+.

Основное меню: правая кнопка мыши. F8 — плейлист, F9 — озвучка.
Язык интерфейса и оформление доступны в меню «Интерфейс».

Обслуживание → Обновления компонентов: проверка и установка обновлений.
Обслуживание → Создать резервную копию: портативный ZIP в папке «Загрузки».
Архив содержит ваши настройки и данные входа TorrServer; это личная копия.
Обслуживание → Настроить TorrServer: адрес и данные входа. Затем перезапустите плеер.

Если сборка расположена в защищённой папке, изменения настроек сохраняются
в %APPDATA%\mpv-plus\settings. Для переносной копии в доступной для записи
папке используется portable_config рядом с плеером.

Сеть и буфер: запас видео, скорость чтения, пропущенные кадры и TorrServer.
Увеличенный буфер помогает при коротких задержках, но не заменяет стабильный источник.

Пропуск заставок и титров доступен, когда в файле или базе есть подходящие таймкоды.
Версии отдельных компонентов и контрольные суммы: portable_config/maintenance/manifest.json.
Сведения об исходниках: LICENSES/SOURCES.txt. Лицензии: LICENSES и SOURCES.
