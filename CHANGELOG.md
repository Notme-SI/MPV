# 1.0.3

- Исправлено сохранение языка и настроек при установке в Program Files.
- Совместимый запускатель mpv.exe расположен рядом с основным mpv+.exe.
- Резервная копия и настройка TorrServer перенесены в меню обслуживания.
- Упрощены плашки и метки пропуска; близкие границы объединяются.

- Исполняемый файл mpv+.exe и обновление компонентов из меню плеера.
- Уточнено распознавание названий и сезонов аниме, добавлено сопоставление каталогов.
- Проверка таймкодов по длительности серии, приоритет встроенных глав и удаление неоднозначных интервалов.
- На полоске перемотки отмечаются только пропуски; интервалы выделены голубым.
