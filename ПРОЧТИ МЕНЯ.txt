mpv+-1.0.1
Переносимая сборка для Windows 10/11 x64. Установка не нужна.

ЗАПУСК
1. Распакуйте всю папку, например в C:\Program Files\mpv+
2. Запустите «Настроить TorrServer.cmd». Укажите тот же сервер, что в Lampa,
   и свои логин/пароль, если требуются.
3. В Lampa Desktop выберите mpv.exe из этой папки как внешний плеер.
   Локальные видео можно просто перетаскивать в окно mpv.

ЧТО ДОБАВЛЕНО
Плейлист TorrServer, кнопки пропуска заставок/рекапов/титров,
автообрезка полос, память озвучки сериала и сохранение размера окна.

УПРАВЛЕНИЕ
Пробел: Пауза / воспроизведение
ПКМ: Меню и настройки
F8 / F9: Серии / озвучка
F: Полный экран
← / →: Перемотка
Колесо мыши: Громкость; над полосой перемотки - перемотка
Ctrl+T: Раздачи TorrServer
Shift+C / Shift+С: Включить / выключить автообрезку
Alt+Backspace: Вернуть исходный кадр
Ctrl+I: Найденные фрагменты для пропуска
Alt+I / Alt+R / Alt+C: Пропустить заставку / рекап / титры

Сочетания с буквами - в английской раскладке; Shift+С работает и в русской.
Панель появляется при наведении снизу, кнопки окна - сверху.
Булавка справа включает «Поверх всех окон».

НАСТРОЙКИ В МЕНЮ (ПКМ)
• Языки по умолчанию - озвучка и субтитры. Изначально: RU и форсированные RU.
• Озвучка → Запоминание для сериала - сохранять выбранную студию между сериями.
  Работает, если дорожки имеют совпадающие названия.
• Масштаб - автообрезка, вписать или заполнить окно. Обрезка занимает несколько
  секунд; заполнение окна может срезать края изображения.
• Интерфейс → Полоса перемотки - заполнение, буфер и метки глав.
• Интерфейс → Значки - «Стекло» или обычное оформление.
• Интерфейс → Язык интерфейса - Русский / English, меняется сразу.
• Изображение - нажмите параметр для ввода числа или используйте - / +.
• Субтитры → Выключить - отключить субтитры.
• Субтитры → Запоминание для сериала - память дорожки и отключения между сериями.
  Если совпадение не найдено, применяются языки по умолчанию.
• Сеть и буфер - восстановление после обрыва, размер буфера и диагностика.
  До 5 попыток восстановления, до 2 при ошибке первого открытия. Esc - отменить.
  Для перематываемого потока возврат примерно на 2 секунды назад.
  Размер буфера действует со следующего открытия. Изначально: Авто.

Названия подстраиваются под язык интерфейса по данным TMDB.
Если перевод не найден, отображается очищенное имя файла.

Кнопка пропуска появляется, когда в подключённых базах есть таймкоды.
Они могут отличаться между раздачами. Самопроизвольной перемотки нет.
Если аниме не распознано: Пропуск заставок → AniSkip: указать аниме и серию.
Названия аниме обновляются автоматически. Для поиска нужен интернет.

ОБНОВЛЕНИЕ
«Обновить mpv+.cmd» проверит версии и предложит обновить: Y - да, N - нет.
Перед установкой закройте mpv. Настройки сохраняются. Автоматических бэкапов нет.
В Program Files запускайте установку обновлений от имени администратора.
Доработки проверяются до замены файлов. Подробнее: portable_config/maintenance/README.txt.

Нет плейлиста - проверьте совпадение адреса и порта TorrServer с Lampa.
После настройки сервера или изменения файлов полностью перезапустите mpv.
«Сохранить бэкап.cmd» создаёт личный ZIP с настройками и данными TorrServer.
Лицензии - LICENSES; состав и исходники - VERSION.txt и SOURCES.txt.
