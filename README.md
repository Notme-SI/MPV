# MPV

Неофициальная сборка MPV для Windows 10/11 x64 с готовыми настройками для Lampa и TorrServer.

**[Скачать установщик или ZIP](https://github.com/Notme-SI/MPV/releases/latest)**

## Возможности

- Обновлённый интерфейс, русский и английский языки.
- Плейлист TorrServer и запоминание озвучки сериала.
- Пропуск заставок, рекапов и титров, если таймкоды есть в подключённых базах.
- Автообрезка чёрных полос и сохранение размера окна.

## Установка

1. Скачайте `MPV-1.0.1-Setup.exe` из Releases и запустите установщик. Для переносимой версии распакуйте весь ZIP.
2. Запустите «Настроить TorrServer» и укажите тот же сервер, что в Lampa.
3. В Lampa выберите установленный `mpv.exe` как внешний плеер.

Локальные видео можно перетаскивать в окно. Меню и настройки открываются правой кнопкой мыши.

Установщик по умолчанию использует `%LOCALAPPDATA%\Programs\MPV`. При повторной установке в ту же папку личные настройки сохраняются. Автоматических бэкапов нет.

## Обновление

Запустите «Обновить MPV»: сначала проверяются версии, затем предлагается установка. Перед обновлением закройте плеер.

Подробности: [инструкция](ПРОЧТИ%20МЕНЯ.txt), [устройство доработок](portable_config/maintenance/README.txt).
