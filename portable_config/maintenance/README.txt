mpv+ — обслуживание компонентов

Обновления и создание резервной копии доступны из меню «Обслуживание».
Резервная копия содержит ваши настройки и данные входа TorrServer.
Инструкция пользователя: README.txt рядом с mpv+.exe.
Подробное руководство: https://github.com/Notme-SI/mpv-plus/blob/main/docs/USAGE.md
Сборка из исходников: BUILD.md в репозитории.

Устройство исходников

scripts — загружаемые mpv скрипты, включая точки входа дополнений сборки.
extensions — собственные модули интерфейса, названий, дорожек и TorrServer.
vendor и SOURCES/upstream — сторонние модули и исходные версии до патчей.
script-opts — чистые настройки по умолчанию; личные изменения сюда не публикуют.
maintenance/manifest.json — версии и контрольные суммы компонентов.
maintenance/patches — точечные изменения сторонних скриптов.

Версия сборки находится в VERSION в корне репозитория. После обновления
компонентов их версии в манифесте могут отличаться от первоначального выпуска.

Обновление

Update-MPV.ps1 проверяет источники, готовит файлы во временной папке,
применяет патчи и запускает проверки совместимости и загрузки скриптов.
Каждая замена патча должна встретиться в исходнике ровно один раз;
при несовпадении компонент пропускается. Выпуски двоичных компонентов
проверяются по опубликованному GitHub digest SHA-256.

Test-Extensions.ps1 и compatibility.lua проверяют расширения перед установкой.
Режим Verify в Update-MPV.ps1 готовит и проверяет обновления без установки;
ему нужны готовая сборка с mpv+.exe и доступ к сети.

Update-Components.ps1 ожидает закрытия плеера, запускает обновление,
при необходимости запрашивает повышение прав и снова открывает плеер.
Журнал: %APPDATA%\mpv-plus\update.log.

Собственные расширения из extensions не перезаписываются сторонними
обновлениями. Для обновления дополнений самой сборки установите новый выпуск.
Откат копирования при ошибке установки компонентов не является постоянной
резервной копией. Для личного архива используйте меню резервного копирования.

Export-MPV.ps1 создаёт личную переносную копию и объединяет настройки
профиля с portable_config. По умолчанию архив сохраняется в
%USERPROFILE%\Downloads. Для восстановления распакуйте его в отдельную
доступную для записи папку и запустите mpv+.exe.
