# mpv+ v1.0.2

### Windows

- 🎬 **Названия:** улучшено распознавание названий и сезонов аниме; язык названий следует языку интерфейса, если перевод доступен.
- ⏭️ **Пропуски:** уточнена проверка таймкодов и выделение участков пропуска.
- 🔧 **Исправления:** язык и настройки сохраняются при установке в Program Files.
- ⬆️ **Обслуживание:** обновление компонентов, настройка TorrServer и резервное копирование доступны из меню плеера.
- 🎨 **Интерфейс:** обновлены плашки и метки пропуска.

Установщик — установка с выбором папки и созданием ярлыков. Портативная версия — распакуйте архив целиком.

Для Lampa Desktop выбирайте `mpv.exe` из папки mpv+. Самостоятельный запуск — `mpv+.exe`. При повторной установке в прежнюю папку личные настройки сохраняются.

Контрольные суммы SHA-256 доступны в блоке **Assets** под именами файлов и в [файле контрольных сумм](https://github.com/Notme-SI/mpv-plus/blob/main/releases/1.0.2/SHA256SUMS.txt). Архивы **Source code** содержат исходники, а не готовый плеер.
