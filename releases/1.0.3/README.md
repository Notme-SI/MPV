# mpv+ 1.0.3

- Добавлено отображение хода обновления компонентов и открытие журнала из меню.
- Улучшена панель загрузки и статистики TorrServer.
- Исправлено обновление при запуске через совместимый запускатель Lampa.
- Исправлено распознавание названия Dandadan и уточнён выбор папки установки.

В выпуск также входят возможности предыдущей версии:

- Улучшено распознавание названий и сезонов аниме; названия отображаются на языке интерфейса, если перевод доступен.
- Уточнена проверка таймкодов. Встроенные метки имеют приоритет, неоднозначные интервалы пропускаются.
- На полоске перемотки выделены участки пропусков заставок, рекапов и титров.
- Обновление компонентов доступно из меню плеера.
- Исправлено сохранение языка и настроек в защищённых папках Windows.
- Бэкап и настройка TorrServer доступны через меню «Обслуживание».
- Исполняемый файл переименован в `mpv+.exe`.


**Скачать:**

- `mpv+-1.0.3-Setup.exe` — установщик для Windows 10/11 x64.
- `mpv+-1.0.3.zip` — портативная версия; распакуйте всю папку.

Для Lampa Desktop выбирайте `mpv.exe` из папки mpv+. Для самостоятельного запуска используйте `mpv+.exe`. При установке поверх предыдущей версии в ту же папку личные настройки сохраняются.

Наличие перевода, таймкодов и онлайн-источников зависит от каталогов и конкретной раздачи.
