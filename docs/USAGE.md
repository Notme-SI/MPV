# Руководство mpv+

## Установка и первый запуск

Скачайте установщик или ZIP на [странице последнего выпуска](https://github.com/Notme-SI/mpv-plus/releases/latest). Поддерживаются Windows 10/11 x64.

Установщик по умолчанию использует `%LOCALAPPDATA%\Programs\mpv-plus`. Портативный ZIP распакуйте целиком в доступную для записи папку. Для самостоятельного запуска откройте `mpv+.exe`, затем перетащите файл в окно либо выберите «Открыть файл» в меню правой кнопки мыши.

## Lampa Desktop и TorrServer

1. Убедитесь, что TorrServer запущен и доступен с компьютера, на котором работает плеер.
2. Откройте в mpv+ «Обслуживание → Настроить TorrServer» и укажите тот же адрес, что используется в Lampa, например `http://127.0.0.1:8090`. Этот адрес подходит только для сервера на том же компьютере; для другого устройства укажите его адрес.
3. Если сервер требует авторизацию, заполните логин и пароль. Нажмите «Сохранить» и перезапустите плеер.
4. В настройках внешнего плеера Lampa Desktop выберите `mpv.exe` из папки mpv+. Названия разделов зависят от версии Lampa.
5. Запустите воспроизведение из Lampa. Через меню «TorrServer → Выбрать сериал» в mpv+ также можно открыть доступные на настроенном сервере раздачи.

`mpv+.exe` — основной плеер. `mpv.exe` — совместимый запускатель, который передаёт аргументы основному плееру. Оставляйте оба файла и `portable_config` вместе. Одна только копия исходников GitHub не содержит готового плеера: для запуска нужен архив из Releases.

## Управление

| Действие | Клавиши или меню |
| --- | --- |
| Основное меню | Правая кнопка мыши, клавиша меню или `Ctrl+P` |
| Плейлист и серии | `F8` |
| Выбор озвучки | `F9` |
| Перемотка на 5 секунд | Стрелки влево / вправо |
| Перемотка на 60 секунд | Стрелки вверх / вниз |
| Громкость | Колесо мыши над видео |
| Включить / отключить автообрезку | `Shift+C` (латинская `C` или русская `С`) |
| Сброс кадра и масштаба | `Alt+Backspace` |
| Выбор, отключение и загрузка субтитров | «Субтитры» |
| Язык интерфейса | «Интерфейс → Язык интерфейса» |
| Яркость, контрастность и другие параметры | «Изображение» |
| Полный экран и «Поверх всех окон» | «Окно» |

Таблица соответствует настройкам поставки в [`input.conf`](../portable_config/input.conf). Изменённый пользователем файл может задавать другое управление.

## Озвучка, субтитры и названия

В меню «Языки по умолчанию» задаются предпочтения. Запоминание выбора для сериала управляется отдельно в «Озвучка → Запоминание для сериала» и «Субтитры → Запоминание для сериала». Плеер запоминает также отключение субтитров. Память можно отключить или сбросить из соответствующего меню.

Дорожки сопоставляются по языку, названию и признаку форсированных субтитров. Если однозначного совпадения нет, используются предпочтения по умолчанию.

Названия запрашиваются на языке интерфейса. Если перевода нет, может отображаться оригинальное название, а если произведение не распознано — очищенное имя файла. Язык названий не меняет выбранные дорожки.

## Пропуск заставок и титров

Меню «Пропуск заставок» показывает найденные фрагменты и позволяет пропустить заставку, рекап или титры. Для аниме доступен пункт «AniSkip: указать аниме и серию», если автоматическое распознавание не подошло.

Наличие фрагментов зависит от глав файла и внешних баз. Встроенные именованные главы имеют приоритет; неподходящие и неоднозначные интервалы отбрасываются. Другая версия монтажа или раздача может иметь другие границы фрагментов.

## Сеть и буфер

В меню «Сеть и буфер» доступны восстановление потока, запас видео, скорость чтения и сведения TorrServer. Дополнительные режимы буфера ограничены 60 секундами / 256 МБ или 180 секундами / 512 МБ и применяются со следующего открытия файла. Фактический запас зависит от битрейта и источника.

При обнаруженном обрыве HTTP-потока плеер делает до пяти повторных попыток, при ошибке первого открытия — до двух. Для перематываемого файла просмотр возобновляется примерно за две секунды до места обрыва. `Esc` отменяет ожидание; ручной выбор другой серии также отменяет повторное подключение. Восстановление начинается после того, как mpv обнаружит ошибку или преждевременный конец потока.

## Обновления

«Обслуживание → Обновления компонентов → Проверить обновления» проверяет сторонние компоненты. При наличии обновлений выберите «Установить и закрыть плеер». Во время установки отображается ход работы; затем плеер открывается снова. Для защищённой папки Windows может запросить повышение прав.

Обновление компонентов не заменяет установку нового выпуска всей сборки. Для обновления собственных расширений mpv+ скачайте новый выпуск и установите его в прежнюю папку. Перед заменой файлов портативной версии закройте плеер и создайте резервную копию настроек; распаковка с заменой файлов может перезаписать конфигурацию.

Установщик сохраняет существующие `portable_config/mpv.conf`, `portable_config/input.conf`, файлы `portable_config/script-opts` и личное состояние. Поэтому новые настройки по умолчанию не заменяют ваши автоматически.

## Настройки и резервная копия

| Данные | Расположение |
| --- | --- |
| Основная конфигурация и клавиши | `portable_config/mpv.conf`, `portable_config/input.conf` рядом с плеером |
| Настройки расширений и их состояние в доступной для записи папке | `portable_config` |
| Изменяемые настройки расширений при защищённой папке | `%APPDATA%\mpv-plus\settings` |
| Манифест компонентов | `portable_config/maintenance/manifest.json` |
| Журнал обновления | `%APPDATA%\mpv-plus\update.log` |

Путь в профиле используется расширениями сборки при невозможности записи в `portable_config`; он не переносит туда автоматически весь `mpv.conf` или `input.conf`.

«Обслуживание → Создать резервную копию» сохраняет архив `mpv+-Backup-<дата-время>.zip` в `%USERPROFILE%\Downloads` и показывает его в Проводнике. Это личная переносная копия плеера с настройками, включая данные входа TorrServer. История `watch_later` / `watch_history` не входит в обычный обход папки плеера при экспорте. Автоматические резервные копии не создаются.

Для восстановления закройте плеер, распакуйте архив в новую доступную для записи папку и запустите `mpv+.exe` из неё. Экспорт объединяет изменяемые настройки профиля с `portable_config`, поэтому отдельная переносная копия может использовать их без установки. Если переносите её на другой компьютер, проверьте адрес TorrServer и пути к файлам. Для использования восстановленной копии в Lampa заново выберите её `mpv.exe`.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Lampa не запускает плеер | Выбран ли `mpv.exe` из готового выпуска; есть ли рядом `mpv+.exe` и `portable_config`; открывается ли основной плеер самостоятельно |
| Нет списка TorrServer или поток не открывается | Адрес, порт, логин и пароль; доступность сервера с этого компьютера; перезапуск плеера после настройки |
| Видео останавливается | Запас видео и скорость в «Сеть и буфер», статистику TorrServer и доступность раздачи; больший буфер помогает при кратких просадках |
| После смены языка название осталось прежним | Доступность перевода в каталоге и распознавание файла; выбранные дорожки на язык названия не влияют |
| Нет кнопки пропуска | Наличие подходящих глав или таймкодов; для аниме попробуйте вручную указать произведение и серию |
| Изменения настроек не видны в папке плеера | При защищённой папке проверьте `%APPDATA%\mpv-plus\settings` |
| Обновление не завершено | «Открыть журнал обновления» в меню обновлений или `%APPDATA%\mpv-plus\update.log`; доступ к GitHub и разрешение записи в папку плеера |
